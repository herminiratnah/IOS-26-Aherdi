1. RINGKASAN EKSEKUTIF (EXECUTIVE SUMMARY)
================================================================================
Aplikasi ini adalah sebuah "Sistem Operasi Alternatif Virtual" (Virtual iOS 26 
Environment) berbasis Android murni yang dirancang menggunakan Kotlin dan 
Jetpack Compose modern.

Bukan sekadar launcher tema biasa (skin/launcher icon), aplikasi ini mengemulasi 
arsitektur, logika interaksi, gesture fisika, persistensi data lokal, hingga 
18+ modul aplikasi bawaan (Settings, Camera, Safari, Phone, Maps, Health, Wallet, 
Music, dll.) dengan interaksi fungsional nyata tanpa tipuan mock data semata.

Aplikasi ini menjembatani hardware Android (Sensor Giroskop, Accelerometer, 
Kamera CameraX, Media Audio, Baterai, Wi-Fi, Telephony, Vibrator Haptic) ke dalam 
antarmuka ultra-mewah standar iOS 26 Material Glassmorphism.

4. MAPPING FITUR LENGKAP (FEATURE BREAKDOWN)
================================================================================

4.1. LOCK SCREEN & DEPTH EFFECT ENGINE (`IOSLockScreenView.kt`)
--------------------------------------------------------------------------------
- Real-time Time & Date Display dengan format dinamis dan multi-bahasa.
- Depth Effect Wallpaper: Jam berada di lapisan tengah (antara background langit
  dan foreground subjek gunung/planet/gedung).
- Keypad Passcode Ergonomis: Tombol bulat diameter 80dp bergaya frosted glass,
  lengkap dengan feedback getar haptik, suara 'click' mekanik iOS, dan animasi
  pegas goyang (shake animation) jika PIN salah.
- Shortcut Bawah Layar: Akses instan senter (Flashlight) dan Kamera tanpa buka kunci.
- Face ID Engine: Simulasi autentikasi biometrik dengan ikon gembok terbuka otomatis.
- Lock Screen Customizer: Long-press di layar kunci memunculkan panel pengubah font,
  warna aksen jam, dan pemilihan widget.

4.2. SPRINGBOARD & HOMESCREEN ENVIRONMENT (`SpringBoardScreen.kt`)
--------------------------------------------------------------------------------
- Multi-page Homescreen Grid dengan indikator titik halaman halus.
- Jiggle Mode (Edit Mode): Ikon bergoyang halus saat ditekan lama dengan badge
  tanda silang (-) untuk menghapus atau menata ulang tata letak aplikasi.
- Widget Stack Dinamis: Widget Jam Analog, Kalender, Cuaca, Galeri Foto, Baterai,
  dan Catatan yang terintegrasi secara visual.
- Dock Bar Bawah: 4 aplikasi prioritas (Phone, Safari, Messages, Music) dengan
  latar belakang material frosted glass.
- Today View (Halaman Kiri Terjauh): Kumpulan kartu widget informatif lengkap.
- App Library (Halaman Kanan Terjauh): Kategorisasi aplikasi otomatis ke dalam
  folder (Utilities, Social, Entertainment, Productivity, Developer).
- Spotlight Search: Tarik layar ke bawah untuk memunculkan bilah pencarian universal
  (mencari aplikasi internal, kontak, maupun web Safari secara instan).

4.3. OVERLAY SISTEM INTERAKTIF
--------------------------------------------------------------------------------
- Dynamic Island (`DynamicIsland.kt`):
  Pil hitam di bagian atas layar kamera yang secara adaptif dapat mengecil atau
  membesar (Compact, Expanded, Mini Pill) untuk memuat info musik yang berputar,
  status pengisian daya, panggilan telepon aktif, dan hitung mundur timer.
- Control Center (`IOSControlCenter.kt`):
  Ditarik dari pojok kanan atas. Menampilkan slider vertikal kecerahan layar,
  slider volume, toggle Wi-Fi, Bluetooth, Airplane Mode, Cellular, Airdrop,
  Focus/DND, Senter, Kalkulator, dan Screen Mirroring.
- Notification Center (`IOSNotificationCenter.kt`):
  Ditarik dari pojok kiri atas/tengah. Menampilkan daftar notifikasi bertumpuk
  (stacked notifications) dengan tombol bersihkan (Clear all).
- iOS App Switcher / Multitasking (`IOSAppSwitcher.kt`):
  Geser Home Bar ke atas dan tahan untuk melihat kartu aplikasi yang sedang berjalan,
  lengkap dengan gesture 'flick up' untuk menutup aplikasi (kill task).
- AssistiveTouch (`AssistiveTouchView.kt`):
  Tombol pintas melayang virtual di tepi layar yang dapat dibuka untuk mengakses
  Home, Control Center, Siri, Device Lock, dan Volume.
- StandBy Mode (`IOSStandByOverlay.kt`):
  Aktif otomatis saat perangkat dalam posisi lanskap + sedang diisi daya listrik.

15. Wallet (`WalletApp.kt`): Apple Pay virtual card visualizer, tambah kartu debit/kredit,
    dan riwayat transaksi digital.
16. Maps (`MapsApp.kt`): Tampilan peta navigasi, pencarian POI, dan rute navigasi.
17. App Store (`AppStoreApp.kt`): Showcase aplikasi populer dan peluncur aplikasi internal.
18. FaceTime (`FaceTimeApp.kt`): Simulasi panggilan video dengan preview kamera langsung.

4.5. FITUR KHUSUS & KEUNGGULAN TAMBAHAN
--------------------------------------------------------------------------------
- iRoot Tools (`RootToolsApp.kt`):
  Dashboard utilitas untuk inspeksi sistem Android (arsitektur prosesor, pemakaian

5. ALUR PIPELINE DATA, STATE & HARDWARE (END-TO-END PIPELINES)
================================================================================

PIPELINE 1: ALUR BUKA KUNCI (LOCK SCREEN TO HOMESCREEN)
--------------------------------------------------------------------------------
1. User menyalakan layar -> `IOSLockScreenView` ter-trigger.
2. Sensor biometrik / Face ID memeriksa wajah via delay coroutine:
   - Jika Face ID aktif -> Animasi scan -> Gembok terbuka -> Play unlock sound -> 
     Transisi `isDeviceLocked = false`.
   - Jika menggunakan Passcode -> User mengetuk layar / geser ke atas -> 
     Keypad muncul -> Input 4 digit angka -> Verifikasi dengan `userPasscode`:
     * Match   : Haptic sukses -> Suara buka kunci -> Masuk ke SpringBoard.
     * Mismatch: Animasi spring shake keypad -> Haptic error -> Reset input.

PIPELINE 2: ALUR DEPTH EFFECT WALLPAPER RENDERING
--------------------------------------------------------------------------------
1. `IOSDepthWallpaperRenderer` membaca `LockScreenConfig` (theme: mountain/planet/dune).
2. Canvas Level 1: Menggambar latar langit, gradasi horizon, dan partikel latar.
3. Canvas Level 2: Merender Teks Waktu / Jam (misal "09:41") dengan font dan warna
   terpilih pada posisi vertikal strategis.
4. Canvas Level 3: Merender Subjek Foreground (Puncak Gunung / Siluet Planet)
   yang menimpa (overlapping) bagian bawah angka jam.
5. Hasil: Menciptakan ilusi optik 3D seolah-olah jam berdiri tegak di belakang 
   puncak gunung di alam nyata.

PIPELINE 3: ALUR SISTEM NAVIGASI & GESTURE (HOME BAR & APP SWITCHER)
--------------------------------------------------------------------------------
1. Dari aplikasi manapun, `HomeBar` selalu melayang di dasar layar.
2. User menggeser (swipe) ke atas secara cepat:
   -> Animasi scaling down jendela aplikasi saat ini.
   -> `activeAppId` diset ke null -> Kembali ke SpringBoard (Home).
3. User menggeser ke atas dan menahan jari (swipe & hold):
   -> `isAppSwitcherOpen = true`.
   -> Grid kartu aplikasi aktif ditampilkan secara horizontal bergaya iOS Carousel.
   -> Geser kartu ke atas -> Aplikasi ditutup dari memori.

PIPELINE 4: ALUR DYNAMIC ISLAND MULTI-TASKING
--------------------------------------------------------------------------------
1. Aplikasi Music memutar lagu atau Clock menyalakan Timer.
2. `IOSViewModel.updateDynamicIsland()` memancarkan state baru ke `StateFlow<DynamicIslandData>`.
3. Komponen `DynamicIsland` di bilah status mendeteksi event -> Mengembang secara halus
   (Spring animate) menampilkan visualizer gelombang suara atau countdown timer.
4. User mengetuk Dynamic Island -> Dynamic Island membesar menjadi banner interaktif
   (Expanded view) dengan tombol kendali (Pause, Skip, Stop).

PIPELINE 5: ALUR BACK TAP HARDWARE DETECTION
--------------------------------------------------------------------------------
1. `SensorEventListener` mendaftarkan pembacaan akselerometer pada sumbu Z (Z-axis peak).
2. Ketika terdeteksi lonjakan percepatan gravitasi spesifik dalam rentang jendela 
   waktu 250-400ms:
3. Algoritma filter membedakan antara guncangan langkah kaki vs ketukan jari di bodi HP.
4. Jika kriteria Double/Triple tap terpenuhi -> Memanggil aksi terpilih (Toggle Flashlight,
   Mute Audio, atau Screenshot).

utama ini:

1. "Bukan Sekadar Launcher, Melainkan Virtual Sub-OS":
   Tunjukkan bahwa aplikasi ini memiliki ekosistem aplikasi utuh di dalamnya 
   (dari kalkulator, browser, pemutar musik, hingga lock screen dengan Depth Effect).

2. "Tingkat Presisi dan Sensasi Fisika (Craftsmanship)":
   Sorot kehalusan animasi geser Home Bar, pantulan pegas (spring feedback), 
   sensasi getar taptic saat menekan tombol keypad, dan responsivitas Dynamic Island.

3. "Inovasi Depth Effect Tanpa Beban GPU Berat":
   Jelaskan bahwa efek jam di balik gunung dibangun dengan algoritma multi-layer canvas
   yang sangat ringan, hemat baterai, dan berjalan mulus tanpa lag di perangkat Android.

4. "Kombinasi Terbaik Dua Dunia (Android x iOS)":
   Pengguna mendapatkan kemewahan dan kerapian estetika iOS 26, namun tetap mempertahankan
   kekuatan keterbukaan Android (akses kamera, file lokal, hardware sensor, dan integrasi
   aplikasi lokal).
