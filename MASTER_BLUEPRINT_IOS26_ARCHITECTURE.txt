BAB 1: VISI PRODUK & RINGKASAN EKSEKUTIF (PRODUCT VISION)
================================================================================
Aplikasi ini bukan sekadar launcher tema grafis (skin/icon pack biasa). Ini adalah
sebuah "Sistem Operasi Virtual Mandiri" (Virtual iOS 26 Operating Sub-Environment) 
yang berjalan di atas kernel dan framework Android murni.

Tujuan rekayasa dari proyek ini adalah:
1. Menghadirkan replika sempurna (Pixel-Perfect & Physics-Accurate) dari pengalaman 
   pengguna Apple iOS 26 / iOS 18 Pro di perangkat Android.
2. Membuka jembatan fungsional nyata:
   - SMS nyata (SMSManager), Telepon nyata (Telecom/Intent), Kontak nyata (ContactsContract),
     Kalender nyata (CalendarContract), dan Alarm nyata.
   - Kamera fisik nyata (Jetpack CameraX) dan Web Browser nyata (Android WebKit).
   - Sensor fisik nyata: Akselerometer untuk Back Tap (ketuk bodi belakang HP) dan
     kamera/LED untuk Senter fisik.
3. Menghadirkan integrasi OS tingkat dalam:
   - Berjalan sebagai Android Default Home Launcher (`CATEGORY_HOME`).
   - Berjalan sebagai System-wide Overlay (`SYSTEM_ALERT_WINDOW`) sehingga Dynamic 
     Island dan Status Bar iOS tetap melayang saat user membuka aplikasi luar (seperti 
     WhatsApp, YouTube, Google Chrome).
   - Memiliki Keyboard iOS virtual bawaan (InputMethodService).
   - Memiliki Root Engine (`su` shell) untuk mematikan SystemUI Android bawaan, 
     mengubah DPI layar (Retina resolution), mem-boost CPU governor, dan mengoptimalkan RAM.

BAB 3: SUBSISTEM LAYANAN SISTEM ANDROID (SERVICES, RECEIVERS, & IME)
================================================================================

3.1. ANDROID DEFAULT HOME LAUNCHER (`MainActivity.kt`)
- Didaftarkan dengan intent-filter:
  `android.intent.action.MAIN`
  `android.intent.category.HOME`
  `android.intent.category.DEFAULT`
  `android.intent.category.LAUNCHER`
- Menjadikan aplikasi ini kandidat sebagai Default Launcher sistem Android.
- Menangani `enableEdgeToEdge()`, menyembunyikan status bar dan navigation bar 
  bawaan Android secara permanen via `WindowInsetsControllerCompat`.
- Menangani siklus hidup (Lifecycle), intent panggilan masuk, SMS broadcast receiver,
  battery level receiver, network connectivity receiver, dan tombol fisik hardware 
  (Volume Up/Down memicu Dynamic Island Volume HUD, Back key memicu navigasi iOS).

3.2. SYSTEM-WIDE OVERLAY SERVICE (`IOSOverlayService.kt`)
- Sebuah Android Foreground Service yang memanfaatkan izin `SYSTEM_ALERT_WINDOW`.
- Menggunakan `WindowManager.addView()` dengan tipe `TYPE_APPLICATION_OVERLAY` untuk 
  menempelkan sebuah `ComposeView` di titik paling atas layar fisik (Y = 0).
- FUNGSI UTAMA: Saat user membuka aplikasi pihak ketiga di luar launcher (misalnya 
  Instagram, YouTube, Mobile Legends, WhatsApp), Dynamic Island dan Status Bar iOS 
  TETAP melayang di atas aplikasi tersebut!
- Terhubung secara reaktif dengan `OverlayBridge.kt` sehingga perubahan state musik, 
  notifikasi masuk, atau pengisian daya di launcher langsung ter-render di overlay.

3.3. NOTIFICATION INTERCEPTION PIPELINE (`IOSNotificationListenerService.kt`)
- Service khusus berizin `BIND_NOTIFICATION_LISTENER_SERVICE`.
- Menangkap setiap notifikasi yang masuk ke ponsel Android (seperti pesan WhatsApp, 
  email Gmail, notifikasi bank, e-commerce, dll.).
- Membedah objek `StatusBarNotification`: mengekstrak judul, isi pesan, package name, 
  ikon aplikasi, dan PendingIntent untuk membuka aplikasi terkait.
- Memancarkan data via `SharedFlow<AppNotificationData>` ke `IOSViewModel`, yang kemudian 
  secara otomatis:
  a) Memunculkan popup ekspansif di Dynamic Island.
  b) Menyimpan ke tumpukan iOS Notification Center.

3.4. VIRTUAL iOS KEYBOARD SERVICE (`IOSKeyboardService.kt`)
- Sebuah `InputMethodService` Android nyata yang didaftarkan di sistem.
- Memberikan keyboard bergaya Apple iOS 26 kepada seluruh sistem operasi Android.
- Fitur keyboard:
  * Layout QWERTY dengan tombol abu-abu frosted, shadow drop iOS, dan tombol spasi lebar.
  * Haptic Feedback presisi dan suara 'clack' mekanik saat mengetik.
  * Tombol Shift dengan indikator panah kapsital, tombol angka & simbol (?123), 
    tombol emoji khusus, dan tombol aksi (Enter/Go/Search/Done).
  * Dapat diaktifkan melalui menu Settings > Language & Input pada perangkat Android.

3.5. PERSISTENCE BOOT RECEIVER (`IOSBootReceiver.kt`)
- BroadcastReceiver dengan `directBootAware="true"` dan prioritas filter 999 
  (`BOOT_COMPLETED`, `LOCKED_BOOT_COMPLETED`, `MY_PACKAGE_REPLACED`).
- Menyelesaikan masalah umum perangkat Android hasil modifikasi (root tweaks):
  Saat HP direstart, Android SystemUI normalnya akan aktif kembali.
- `IOSBootReceiver` secara otomatis memeriksa SharedPreferences: jika user sebelumnya 
  mematikan SystemUI atau mengaktifkan CPU governor / 120Hz via iRoot, receiver ini 
  langsung mengeksekusi script root su di background begitu HP menyala sehingga 
  tampilan iOS tetap utuh tanpa terputus!

BAB 4: ENGINE INTI, UTILITAS, & HARDWARE BRIDGES
================================================================================

4.1. ROOT EXECUTION ENGINE (`RootExecutor.kt`)
- Engine eksekusi shell tingkat rendah (Low-Level Process Pipe).
- Mengecek ketersediaan `su` binary (`/system/bin/su`, `/system/xbin/su`, Magisk, KernelSU) 
  dan fallback ke `sh`.
- Kemampuan khusus:
  * `killAndroidBars()`: Mematikan bar navigasi dan status bar bawaan via policy control.
  * `disableSystemUICompletely()`: Mematikan paket `com.android.systemui` secara permanen, 
    memblokir pull-down shade via `service call statusbar 1 i32 65536`, dan menulis 
    skrip boot Magisk di `/data/adb/service.d/iroot_init.sh`.
  * `boostCpuGovernor()`: Menyetel governor semua inti CPU ke mode `performance`.
  * `optimizeJ2PrimeRam()`: Menghapus drop_caches (`echo 3 > /proc/sys/vm/drop_caches`) 
    dan mengompresi memori ZRAM untuk perangkat ber-RAM kecil (seperti 1.5GB).
  * `setIosRetinaDpi(dpi)`: Mengubah resolusi visual via `wm density`.
  * `spoofIphoneModel()`: Memodifikasi properti build (`ro.product.model`, `ro.product.brand`) 
    menjadi "iPhone 16 Pro Max" atau "iPhone SE".

4.2. ACCELEROMETER GESTURE ENGINE (`BackTapDetector.kt`)
- Menggunakan `SensorManager` Android membaca `Sensor.TYPE_ACCELEROMETER`.
- Melacak lonjakan akselerasi pada sumbu Z (Z-axis spike) saat bagian belakang casing HP diketuk.
- Menggunakan algoritma jendela waktu (time-window 250ms - 400ms) dan threshold percepatan 
  untuk membedakan antara guncangan langkah kaki berjalan vs ketukan jari pengguna.
- Mendukung dua gesture:
  * Double Tap (Ketuk 2x): Contoh pemicu Senter, Screenshot, atau Mute.
  * Triple Tap (Ketuk 3x): Contoh pemicu Control Center atau Lock Screen.

4.3. PERSISTENCE & LOCAL STORAGE MANAGER (`IOSPersistenceManager.kt`)
- Pengelola penyimpanan lokal terpadu (Unified Storage Engine).
- Mengintegrasikan SharedPreferences, file internal privat, dan ContentResolver Android.
- Menyimpan:
  * Alarms (sinkronisasi dengan `AlarmClock.ACTION_SET_ALARM`).
  * Calendar Events (sinkronisasi dengan `CalendarContract.Events`).
  * To-Do Reminders dengan kategori dan warna bendera.
  * Notes lengkap dengan judul, isi teks, dan timestamp.
  * Wallpaper pilihan pengguna, konfigurasi Depth Effect (Mountain, Planet, Dune, Skyline), 
    font jam, warna jam, dan widget Lock Screen.
  * Custom App Icons (file gambar yang dipetakan ke aplikasi tertentu).
  * Preferensi Action Button, Camera Control, Focus Mode, dan Back Tap.

4.4. AUDIO, HAPTIC & FEEDBACK SUITE
- `IOSFeedbackHelper.kt`: Menghasilkan getaran haptik presisi mikro (Light, Medium, 
  Heavy, Success, Warning, Error) menggunakan `VibrationEffect` modern.
- `FlashlightHelper.kt`: Mengendalikan LED flash fisik kamera secara langsung via 
  `CameraManager.setTorchMode()`.

BAB 5: CENTRAL STATE ORCHESTRATOR (IOSViewModel - 3270+ LINES)
================================================================================
`IOSViewModel.kt` adalah otak pusat pengendali seluruh ekosistem aplikasi. Menggunakan 
pola `AndroidViewModel` dengan puluhan `StateFlow` dan `MutableStateFlow` yang menjamin 
sifat reaktif dan thread-safe.

5.1. STATE MANAGEMENT SUBSYSTEMS
- Layar & Navigasi:
  `activeApp`: Menyimpan aplikasi yang sedang terbuka (null = SpringBoard/Home).
  `recentApps`: Daftar kartu aplikasi multitasking di App Switcher.
  `isControlCenterOpen`, `isNotificationCenterOpen`, `isSpotlightOpen`, `isSiriOpen`,
  `isStandByOpen`, `isShareSheetOpen`, `isAppSwitcherOpen`.
- Keamanan & Lock Screen:
  `isDeviceLocked`: Menentukan apakah layar dalam status terkunci.
  `userPasscode`: Kode PIN 4 atau 6 digit.
  `isFaceIdEnabled`: Menentukan apakah sensor biometrik/wajah aktif.
  `lockScreenConfig`: Pengaturan visual Depth Effect, Font jam, dan Widget.
- Hardware & Telemetri Real-time:
  `batteryLevel`, `isBatteryCharging`, `isWifiConnected`, `cellularBars`, `networkType`,
  `volume`, `brightness`, `flashlightEnabled`, `isAirplaneMode`.

5.2. TELEPHONY, SMS & CONTACTS PIPELINE
- `loadDeviceContacts()`: Mengambil daftar kontak nyata dari `ContactsContract`.
- `addNewContact()`: Menulis kontak baru langsung ke database kontak Android.
- `makeRealPhoneCall()`: Memulai panggilan suara melalui Android Telecom subsystem.
- `loadDeviceSms()`: Membaca inbox pesan SMS dari `Telephony.Sms.CONTENT_URI`.
- `sendRealSms()`: Mengirim SMS nyata via `SmsManager.getDefault().sendTextMessage()`.
- `onIncomingCallReceived()` & `answerIncomingCall()`: Menampilkan banner panggilan 
  masuk di Dynamic Island dengan opsi jawab atau tolak.

5.3. AUDIO PLAYER & LIVE SYNTHESIZER
- `loadLocalMusic()`: Memindai file `.mp3` dan `.m4a` dari penyimpanan perangkat via MediaStore.
- `playSong()`: Memutar audio menggunakan instance `MediaPlayer`.
- `startAudioSynthesizer()`: Jika tidak ada file musik di HP, sistem menyediakan 
  synthesizer gelombang audio bawaan sehingga pemutar musik dan visualizer Dynamic 
  Island tetap berfungsi dan bersuara merdu secara nyata!
- Terkoneksi ke Dynamic Island (menampilkan waveform animasi, album art, dan timer lagu).

5.4. KONEKTIVITAS & PUSAT KENDALI
- Wi-Fi Manager: Scan jaringan sekitar (`scanWifiNetworks`), menyambungkan ke SSID 
  dengan password (`connectToWifi`), toggle status on/off.
- Bluetooth Manager: Menyalakan/mematikan Bluetooth, scanning perangkat sekitar, dan pairing.
- Hotspot & Cellular Data toggle via shell/system API.

  Animasi ikon gembok berputar yang membuka otomatis saat wajah terdeteksi.

7.2. DYNAMIC ISLAND MULTI-MODE ADAPTIF (`DynamicIsland.kt`)
- Pil hitam interaktif di bagian atas layar kamera yang memiliki 4 mode ukuran:
  1. Mini Capsule: Mode siaga standar yang menyatu dengan kamera depan.
  2. Compact State: Menampilkan ikon kecil di kiri dan teks/waveform di kanan (misal ikon musik).
  3. Expanded State: Membesar saat disentuh, memunculkan kontrol pemutar musik penuh, 
     countdown timer besar dengan tombol stop, atau banner panggilan telepon masuk.
  4. Notification Alert: Melebar secara dinamis saat ada pesan WhatsApp atau notifikasi masuk.
- Dilengkapi animasi pegas fluida (Spring Animation) standar iOS.

7.3. CONTROL CENTER & NOTIFICATION CENTER
- `IOSControlCenter.kt`: Ditarik dari pojok kanan atas layar.
  * Slider kecerahan dan volume vertikal dengan persentase real-time.
  * Pod 4 toggle konektivitas (Airplane, Seluler, Wi-Fi, Bluetooth).
  * Toggle Senter fisik, Kalkulator, Rotasi Layar, Timer, dan Mode Fokus/DND.
- `IOSNotificationCenter.kt`: Ditarik dari pojok kiri atas/tengah layar.
  * Daftar notifikasi bertumpuk (stacked cards) dari sistem Android.
  * Tombol bersihkan semua notifikasi dan jam digital Lock Screen sekunder.

7.4. HOME BAR, APP SWITCHER & GESTUR FISIKA
- `HomeBar.kt`:
  Bilah horizontal melayang di dasar layar yang mendeteksi gestur geser pengguna:
  * Swipe Up Cepat: Menutup aplikasi saat ini dan kembali ke SpringBoard dengan animasi mengecil.
  * Swipe Up & Hold: Membuka iOS App Switcher (`IOSAppSwitcher.kt`).
- `IOSAppSwitcher.kt`:
  Tampilan multitasking carousel dengan kartu-kartu aplikasi 3D.
  Geser kartu ke atas (flick up) untuk mematikan proses aplikasi dari memori.

7.5. SIRI APPLE INTELLIGENCE & SPOTLIGHT SEARCH
- `SiriOverlay.kt`:
  Pendaran cahaya neon multi-warna mengelilingi seluruh tepi layar ponsel (Apple Intelligence glow), 
  disertai visualizer gelombang suara dan saran aksi cepat.
- `SpotlightSearchOverlay.kt`:
  Tarik ke bawah dari tengah SpringBoard untuk memunculkan pencarian universal: mencari aplikasi 
  internal, aplikasi Android luar, nomor kontak, perhitungan matematika cepat, dan web query.

7.6. STANDBY MODE, ASSISTIVETOUCH, & PERFORMANCE HUD
- `IOSStandByOverlay.kt`:
  Aktif otomatis saat perangkat dicolokkan ke pengisi daya listrik dalam orientasi lanskap. 
  Menampilkan jam meja format besar, kalender, dan Night Mode merah temaram.
- `AssistiveTouchView.kt`:
  Tombol pintas bundar melayang di layar yang dapat dipindah-pindah, membuka menu jalan pintas 
  Home, Control Center, Siri, Kunci Layar, dan Volume.
- `IOSFpsOverlay.kt`:
  Indikator performa frame-rate (FPS) real-time berbasis `Choreographer` untuk memantau 
  kehalusan animasi antarmuka 60-120Hz.

BAB 8: PIPELINE END-TO-END DATA & KONTROL (SEKUENS ALUR EKSEKUSI)
================================================================================

PIPELINE 1: ALUR NOTIFIKASI PIHAK KETIGA KE DYNAMIC ISLAND & NOTIF CENTER
--------------------------------------------------------------------------------
1. Pesan WhatsApp / SMS / Notifikasi masuk ke perangkat Android.
2. Android OS memicu `IOSNotificationListenerService.onNotificationPosted()`.
3. Service mengekstrak `packageName`, `title`, `text`, dan `PendingIntent`.
4. Data dipancarkan ke `IOSNotificationListenerService.notificationFlow`.
5. `MainActivity` dan `IOSOverlayService` menangkap flow tersebut.
6. `IOSViewModel.addNotification()` menyimpan item ke tumpukan Notification Center.
7. `IOSViewModel.showDynamicIslandNotification()` memicu animasi mengembang pada 
   Dynamic Island di layar.
8. Pengguna mengetuk Dynamic Island -> `PendingIntent.send()` dieksekusi -> Aplikasi 
   WhatsApp asli langsung terbuka!

PIPELINE 2: ALUR DEPTH EFFECT RENDERING PADA LOCK SCREEN
--------------------------------------------------------------------------------
1. Pengguna memilih wallpaper bertema Depth Effect (misal Alpine Mountain Peak).
2. `IOSDepthWallpaperRenderer` menerima `LockScreenConfig` dan membagi kanvas menjadi 3 lapisan:
   - LAPISAN 1 (Background): Merender langit bergradasi senja/fajar, kabut gunung, atau bintang kosmik.
   - LAPISAN 2 (Jam Raksasa): Merender teks waktu "09:41" dengan font dan warna pilihan 
     pada koordinat vertikal tepat di bawah puncak gunung.
   - LAPISAN 3 (Foreground Subject): Merender siluet puncak gunung bersalju dengan kontur 
     presisi di atas angka jam, sehingga bagian bawah jam tertutup secara alami.
3. Hasil: Menghasilkan efek 3D spasial di mana jam tampak nyata berdiri di belakang gunung.

PIPELINE 3: ALUR GESTUR BACK TAP (KETUK BELAKANG CASING HP)
--------------------------------------------------------------------------------
1. `BackTapDetector` memantau sinyal `Sensor.TYPE_ACCELEROMETER`.
2. Pengguna mengetuk bodi belakang ponsel dua kali dengan jari.
3. Gelombang getaran Z-axis menghasilkan dua lonjakan percepatan tajam dalam selang waktu 
   250ms - 400ms.
4. Algoritma filter memastikan lonjakan bukan berasal dari langkah kaki atau guncangan mobil.
5. Callback `onDoubleTap()` dipanggil -> `IOSViewModel.triggerBackTapAction()`.
6. Aksi dijalankan seketika (misal menyalakan Senter LED via `CameraManager` atau menangkap layar).
7. Notifikasi ringkas muncul di Dynamic Island ("Back Tap: Senter Menyala").

PIPELINE 4: ALUR EKSEKUSI ROOT TWEAKS & PERSISTENSI REBOOT
--------------------------------------------------------------------------------
1. Pengguna membuka aplikasi `Root Tools` -> Menekan tombol "Matikan SystemUI Android".
2. `RootToolsApp` memanggil `IOSViewModel.disableSystemUICompletelyRoot()`.
3. `RootExecutor` menjalankan perintah su:
   - `settings put global policy_control immersive.navigation=*`
   - `service call statusbar 1 i32 65536` (memblokir tarikan status bar Android).
   - `pm disable-user --user 0 com.android.systemui` (mematikan paket SystemUI).
4. `RootExecutor` menulis skrip shell ke `/data/adb/service.d/iroot_init.sh`.
5. Status disimpan ke `IOSPersistenceManager.saveRootBoolean("systemui_disabled", true)`.
6. Saat pengguna me-reboot HP -> `IOSBootReceiver` menerima sinyal `BOOT_COMPLETED` 
   dan mengeksekusi ulang script pematian SystemUI secara instan sebelum layar menyala!
